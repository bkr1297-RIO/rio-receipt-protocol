# Federated Crossing Fixture v0.1

## Standing

This is a two-jurisdiction, fixture-local, synthetic, zero-egress composition
of the already-merged single-domain Occurrence-to-Return closure mechanics.

```text
TWO_JURISDICTION_FEDERATED_CROSSING_FIXTURE_LOCAL_SYNTHETIC_ZERO_EGRESS
```

It types and exercises `CampusRef`, `SharedWorld`, `Door`, `Crossing`,
`CrossingTrace`, `CrossingEvidence`, MUS Receipt, Settlement, and separate
Return/Acknowledgement pairs for each campus.

## Fixed distinctions

```text
Campus jurisdiction != actor authority
Door != Crossing != Trace != Receipt != ComplianceAssessment
Shared encounter != shared succession
```

A Door admits a bounded possibility. The Crossing records an occurrence. The
Trace reconstructs a declared fixture route but explicitly does not establish
lawfulness. Evidence supports only the local proposition. Compliance is typed
as `NOT_ASSESSED_FOR_CONSTITUTIONAL_LAWFULNESS`. Each campus receives and
acknowledges its own Return; neither Return creates shared succession.

The two Doors are directional permissions: Campus A → SharedWorld and
SharedWorld → Campus B. Each remains signed under the relevant campus's
jurisdictional envelope; a campus envelope is not collapsed into a single
actor authority.

## Not established

This does not establish production federation, live authority, independent key
custody, external observation/effect, a shared law evaluator, constitutional
lawfulness, shared succession, or Human Return.
