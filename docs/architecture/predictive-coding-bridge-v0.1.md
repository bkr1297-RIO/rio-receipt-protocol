## 1. Purpose

This document uses predictive coding as a pattern bridge between human nervous-system regulation and ONE/RIO/MUSS digital prediction governance.

Predictive coding is useful here as a model for:

- generative models
- prediction
- prediction error
- precision weighting
- active inference
- recalibration

This document does not claim that predictive coding is a complete or settled universal law of the brain, nor that a digital system is biologically equivalent to a human nervous system.

---

## 2. Core bridge

Human predictive coding can be translated into digital prediction governance:

```text
Generative model
→ prediction
→ incoming signal
→ prediction error / delta
→ precision weighting
→ gate posture
→ feedback
→ recalibration
```

In ONE/RIO/MUSS:

```text
Human-authored reference model
→ machine prediction
→ signal/proposal/tool state
→ coherence or authority delta
→ trust/evidence weighting
→ RIO gate
→ MUSS receipt
→ human-authorized update
```

## 3. Concept mapping

| Predictive-coding concept | Human nervous-system meaning | ONE/RIO/MUSS translation |
|---|---|---|
| Generative model | Brain/body model of expected state | Constitution, protocols, context graph, active delegations |
| Prediction | Expected sensory/body/world state | Expected valid system/action state |
| Sensory input | Body/world signals | User input, model output, tool state, external event |
| Prediction error | Mismatch between expected and actual signal | Delta between proposed/actual state and authorized/reference state |
| Precision weighting | How much weight the system gives a signal | Trust weighting: source reliability, evidence, freshness, consequence |
| Active inference | Action to reduce mismatch | Bounded execution after RIO gate |
| Plasticity | Updating future predictions | Human-authorized protocol/memory/policy update |
| Dysregulation | Misweighted predictions/errors or failed feedback | Drift, stale context, overblocking, overconfidence, unreceipted action |

## 5. Meta Layer implication

The Meta Layer monitors expected state versus actual/proposed state.

It should surface:

- expected authority vs. actual authority
- expected scope vs. proposed scope
- expected intent vs. action packet
- expected proof path vs. receipt availability
- expected confidence vs. evidence support
- expected role boundary vs. actual behavior
- expected context freshness vs. stale data
- expected human protocol vs. inferred user state

Meta detects mismatch. RIO governs consequence. MUSS proves return. Human authorizes update.

---

## 6. MANTIS as prediction-error witness

MANTIS functions as prediction-error witness.

It watches for mismatches between:

- prediction and actual signal
- model confidence and evidence support
- human pattern and machine proposal
- declared protocol and inferred action
- active delegation and attempted consequence
- expected receipt path and available proof

MANTIS may surface mismatch. It may not authorize consequence.

---

## 7. Precision weighting

Precision weighting becomes trust weighting in the digital system.

The system should ask:

```text
How reliable is this signal?
How fresh is this context?
How supported is this claim?
How much do models converge or diverge?
What is the consequence if wrong?
Does valid authority exist?
Can this be receipted?
```

Keeper line:

```text
Precision weighting is trust weighting, not authority granting.
```

---

## 8. Prediction-to-authority boundary

A prediction may become a proposal. A proposal may become consequence only through valid authority.

The following do not grant authority:

- prediction
- convergence
- high probability
- confidence
- correctness
- resonance
- pattern completion
- speed
- ease
- capability

Keeper line:

```text
Prediction may prepare the crossing. Authority decides whether the crossing may occur.
```

---

## 9. Digital dysregulation patterns

Predictive dysregulation can appear digitally as:

- stale context treated as current
- confidence greater than evidence
- prediction treated as authority
- convergence treated as proof
- old permission treated as live authority
- repeated warnings creating fatigue
- missed weak signals
- recursive agent loops
- governance blocking valid human intent without appeal

Control pattern:

```text
surface delta
→ slow the crossing
→ return to reference
→ receipt the event
→ recalibrate under human authority
```
